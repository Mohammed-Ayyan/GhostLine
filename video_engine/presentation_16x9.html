Get Started in 3 Simple Steps

1
Download Release
Grab the Windows Installer (Ghostline-Setup.exe) or the portable standalone package from GitHub Releases.
2
Choose AI Provider
Run 100% private locally via Ollama, or connect your BYOK cloud keys (OpenAI, Anthropic, Gemini, Groq) encrypted with DPAPI.
3
Use Global Hotkeys
Press Alt + / to solve questions under your cursor, or Alt + Q for the live audio assistant.

Instant Screen Solve

Press Alt + / to capture and solve the question under your mouse cursor, or Alt + Shift + / for the full active screen.
