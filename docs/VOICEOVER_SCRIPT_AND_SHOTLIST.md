## Executive Summary & Product Truth
Ghostline is an authentic, local-first Windows AI copilot designed for real-time exam assistance, screen context extraction, and live meeting/interview transcription.  
Both videos demonstrate **100% genuine application behavior**:
1. Genuine Windows desktop, taskbar, and notification tray integration.
2. Real floating PyQt6 HUD overlay with draggable title bar, collapse/expand toggle, and copy interactions.
3. Actual screen capture pipeline (`Alt + /`), native OCR parsing, and instant MCQ option detection.
4. Real stealth hardware indicators: Caps Lock LED toggle and Windows system tray status badge.
5. Live audio transcription pipeline (`Alt + A`), dual-channel microphone + WASAPI system loopback capture, speech intent filtering, and multi-turn history retention.
6. The main dashboard is minimized and never dominates the frame.
