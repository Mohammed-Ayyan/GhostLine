Operating System & Assessment Platform Diagnostic Notes:
  • Windows Display Affinity: Protected assessment applications or browsers running with SetWindowDisplayAffinity(WDA_MONITOR) obscure screen contents with uniform black rectangles. Ghostline now detects blank captures and logs explicit diagnostics.
  • User Interface Privilege Isolation (UIPI): When an assessment tool runs with elevated administrative integrity, non-elevated desktop processes cannot inject synthetic keystrokes. Ghostline uses SendInput and verifies hardware state transitions.
  • Scrollable HUD: Dedicated Canvas viewport guarantees header persistence, word wrap, selectable text, and copy-code capabilities regardless of response length.
