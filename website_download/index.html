Windows Setup & Security Guide

Step-by-step visual instructions to configure Windows 11 & 10 for Ghostline. Learn how to verify SmartScreen safety, pin icons, configure system audio loopback, and manage offline AI models.

1. SmartScreen Reputation Warning vs. Antivirus Detection

When running newly downloaded open-source software, Windows distinguishes between a cloud reputation filter and an actual malware detection.

Reputation Filter
Microsoft Defender SmartScreen

Triggers when a file has low global download volume or comes from an unrecognized open-source publisher. Ghostline does not buy $500+/year corporate EV certificates, so Windows initially flags newly compiled binaries as "Unknown Publisher".

Status: Safe to bypass after cryptographic hash verification.
Antivirus Detection
Microsoft Defender Antivirus

Triggers only when a specific malware or trojan pattern name (e.g., Trojan:Win32/...) is matched. The file is actively quarantined in Protection History. Clean Ghostline releases contain zero malware signatures.

Status: If triggered on PyInstaller loaders, report false positive.

Handling Antivirus Quarantine & Reporting False Positives

1
Check Protection History: Open Windows Security (Win + S → type "Windows Security") → Virus & threat protection → click Protection history.
2
Inspect Quarantined Item: Confirm the blocked path points to %LOCALAPPDATA%\Programs\Ghostline\Ghostline.exe. If quarantined mistakenly, select Actions → Restore.
3
Submit Sample to Microsoft: Report the false detection directly to Microsoft Security Intelligence File Submission under "Incorrectly detected as malware / false positive".
🚨
Strict Security Advice: Never disable Windows Defender Real-Time Protection and never create whole-drive exclusions (such as excluding all of C:\ or Downloads). If an exclusion is ever required after SHA-256 verification, limit it strictly to the single verified executable path: %LOCALAPPDATA%\Programs\Ghostline\Ghostline.exe.

3. Microphone Permissions & Sound Loopback Configuration

Ghostline captures both your voice and meeting audio (Zoom, Microsoft Teams, Google Meet, Discord) using native Windows WASAPI loopback without virtual audio cables.

Granting Windows Microphone Access

If pressing Alt + L produces no transcription, Windows Privacy settings may be blocking desktop audio input:

1
Open Settings (Win + I) → Privacy & security (or Privacy on Win 10) → Microphone.
2
Ensure Microphone access is toggled On.
3
Scroll down to the desktop section and ensure Let desktop apps access your microphone is turned On.
🎧
Zero Virtual Audio Cables Required: Ghostline uses the high-performance Windows Audio Session API (WASAPI Loopback) to capture system sound directly from your active headphones or speakers. You do not need to install "Stereo Mix" or third-party virtual cable drivers.

Sound Devices & Exclusive Mode Troubleshooting

If system audio is not captured during video calls:

1
Press Win + R, type mmsys.cpl, and press Enter to open the Windows Sound Control Panel.
2
Under the Playback tab, ensure your primary headset or speakers are marked as Default Device.
3
Right-click your playback device → Properties → Advanced tab → If audio recording fails, uncheck "Allow applications to take exclusive control of this device".

4. Display Scaling, Multi-Monitor & Hotkey Conflicts

Optimize window positioning across multiple monitors, configure high-DPI scaling, and resolve keyboard shortcut overlaps.

🖥️ High-DPI Scaling (125%, 150%, 200%)

Ghostline is built with full Per-Monitor DPI awareness. The HUD overlay and main dashboard automatically adapt to your display scaling. To adjust Windows scale: Settings → System → Display → Scale.

🧭 Multi-Monitor Window Recovery

If you unplug an external display and Ghostline's HUD is positioned off-screen, press Ctrl + Shift + P to reset the HUD to your current cursor position, or use Alt + Space then M to move the main window with arrow keys.

Resolving Keyboard Shortcut Conflicts

If Alt + / (Screen Solve) or Alt + L (Audio Listen) conflicts with another application (such as an IDE, Discord, or NVIDIA GeForce Experience):

1
Open Ghostline and click Settings in the navigation sidebar.
2
Under General Settings → Shortcuts, change the hotkey combination to your preferred key (e.g. Ctrl+Shift+F).
3
Alternatively, you can trigger Screen Solve and Audio Transcription directly from the System Tray menu without any keyboard shortcut.

5. Firewall Rules, Local Ollama Models & Clean Updates

Understand Ghostline's Zero-Socket local network architecture, local model readiness, and update procedures.

Windows Defender Firewall Prompts

Ghostline communicates with Ollama strictly over the local loopback interface (127.0.0.1:11434). It does not open any inbound ports to the external internet:

✓ Private Networks (Home or Work)

Safe to allow. Needed by local services communicating on your internal loopback.

✗ Public Networks (Cafes, Airports)

Always uncheck. Ghostline does not need public network access.

App Updates & Clean Uninstallation

🔄 Preserving Settings on Updates

Ghostline stores your custom settings, model preferences, and question history in %APPDATA%\Ghostline. Running a newer installer updates program files while preserving your data.

🗑️ Clean Uninstallation

Uninstall via Windows Settings → Apps → Installed apps → Ghostline → Uninstall. The uninstaller removes all shortcuts, program files, and registry entries, giving you the choice to keep or purge saved data.

Frequently Asked Questions

Common questions regarding privacy, models, and usage.

Does Ghostline ever send my screen data to the cloud?
No. Ghostline operates under a strict Zero-Socket boundary. All OCR processing and LLM reasoning occur locally on your machine at 127.0.0.1:11434. No data ever leaves your computer.
What happens if Alt + / conflicts with another app?
You can customize your hotkey in the in-app Settings view, or trigger answers directly from the Windows System Tray menu.
How does the Caps Lock physical indicator work?
When enabled, Ghostline gently pulses your keyboard's Caps Lock LED (1 pulse for Option A, 2 for B, 3 for C, 4 for D) using comfortable 300ms timing, automatically restoring your initial typing state.
Where is my local history and settings stored?
Your data is stored strictly in your user profile under %APPDATA%\Ghostline. It is never synced to external servers.
