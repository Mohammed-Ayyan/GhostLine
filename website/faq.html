Frequently Asked Questions

Everything you need to know about setting up, configuring, and using Ghostline on Windows.

Why does Windows SmartScreen show "Windows protected your PC"?

Microsoft Windows SmartScreen flags new or community open-source executables that do not have an expensive Extended Validation (EV) code-signing certificate (which costs hundreds of dollars annually).

Ghostline is completely open source under the MIT license. To run it:

  1. Click "More info" on the blue SmartScreen prompt.
  2. Click the "Run anyway" button.

You can independently verify that our build matches our GitHub source by checking the cryptographic SHA-256 hash published in SHA256SUMS.txt.

Does Ghostline require an internet connection?

No. In local mode, Ghostline runs 100% offline. Screen text is recognized using Windows native OCR (Windows.Media.Ocr), speech is transcribed using local faster-whisper, and reasoning is performed by Ollama on your CPU or GPU. Zero packets leave your PC.

If you choose to use cloud AI (OpenAI, Gemini, Groq, Claude), Ghostline will connect securely via encrypted HTTPS strictly to your configured provider using your personal API key.

How does Ghostline remain hidden during screen shares?

Ghostline applies the native Windows API flag WDA_EXCLUDEFROMCAPTURE to its floating overlay window. Windows Desktop Window Manager automatically excludes this window from capture APIs used by Zoom, Microsoft Teams, Slack, Google Meet, and OBS. Meeting participants see only what is beneath Ghostline.

What are the minimum hardware requirements?

Ghostline runs smoothly on modern dual-core or quad-core Intel/AMD CPUs with at least 8 GB of RAM. For 7B local models (like Mistral 7B or Qwen 2.5 Coder), 16 GB of RAM is recommended. If you have an NVIDIA or AMD GPU, Ollama will automatically offload layers for up to 5x faster token generation.

Does Ghostline work with multiple monitors with different DPI scalings?

Yes! Ghostline is fully Per-Monitor V2 DPI aware. Whether you have a 4K 150% scaled primary display and a 1080p 100% secondary display, Ghostline automatically computes coordinate offsets and renders crisp vector Fluent 2 UI components without blurriness or displacement.

How does candidate profile grounding work in interview mode?

In the My Profile tab in Settings, you can paste or upload your resume (PDF, DOCX, TXT) with your education, skills, and past projects. During technical interviews, when the interviewer asks behavioral or background questions, Ghostline speaks from the first-person candidate perspective (e.g., "I built a high-throughput microservice...") using your authentic facts, never introducing itself as an AI.

How do I safely terminate Ghostline in an emergency?

Press the global emergency hotkey: Ctrl + Alt + Q. This immediately terminates all Ghostline processes, workers, and background threads cleanly.
