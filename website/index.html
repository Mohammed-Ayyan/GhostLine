Engineered for High-Stakes Performance

Explore the six architectural pillars powering Ghostline on Windows.

Instant Screen Question Solve (Alt + /)

Hover your cursor over any LeetCode problem, multiple-choice quiz, or system design prompt and press Alt + /. Windows native OCR extracts screen text sub-millisecond on CPU, parses context, and renders verified solutions in the floating HUD.

[OCR] Extracted 420 chars in 0.04s → Option C (Binary Min-Heap) Verified

Dual-Stream Meeting Copilot

WASAPI loopback captures remote call audio while your microphone captures speech. Ghostline transcribes both streams, prevents echo, and suggests live first-person answers.

Honest Candidate Grounding

Ghostline speaks as you, grounding answers in your authentic resume, education, and tech stack. It never introduces itself as an AI assistant and never invents qualifications.

100% Offline Privacy

Air-gap your intelligence. Run lightweight 3B–8B models locally with Ollama. Zero network packets, zero cloud logs, and zero subscription costs.

Stealth Hardware Signalling

Screen-share safe. Blinks your physical keyboard LEDs (Caps Lock, Num Lock, or Scroll Lock) to signal answers (1=A, 2=B, 3=C, 4=D) without any on-screen popups.

Windows DPAPI Hardware Encryption & Zero Telemetry

When using cloud providers (Groq, xAI, OpenAI, Gemini), API keys are encrypted with Windows DPAPI (CryptProtectData) locked to your Windows user account. Ghostline contains zero telemetry beacons, tracking scripts, or remote logging.

How Ghostline Works

Three streamlined stages from on-screen prompt to actionable assistance.

01

Capture & Recognize

Hover your cursor and press Alt + /. Ghostline captures the local screen region and executes native Windows OCR via the Windows Runtime engine with zero console flashing.

02

Ground & Route

The classifier detects whether the prompt is an MCQ, Code snippet, or open theory. If relevant, your local personal background facts are applied to ground answers.

03

Solve & Overlay

Your chosen model (local Ollama or cloud BYOK) processes the prompt. Solutions appear in the non-intrusive floating HUD with syntax-highlighted code and verified explanations.

Set Up in About 3 Minutes

Choose the workflow that fits your hardware and privacy requirements.

Path A: 100% Offline with Ollama

Recommended for maximum privacy and zero cloud dependencies.

  1. Install Ollama from ollama.com.
  2. Pull your model in Terminal: ollama run qwen2.5:3b
  3. Launch Ghostline — it auto-detects your running Ollama daemon.

Path B: Bring Your Own API Key (BYOK)

Ideal for thin-and-light laptops without a dedicated GPU.

  1. Open Ghostline Settings → AI Model.
  2. Choose OpenAI, Anthropic, Google Gemini, Groq, or xAI.
  3. Paste your API key. It is hardware-encrypted with Windows DPAPI.

Global Hotkeys

Instant shortcuts that work across any desktop application.

Opens the Live Meeting Assistant window to transcribe speaker streams and generate conversational suggestions.

Immediately kills all background threads, releases audio loopbacks, and exits Ghostline.
