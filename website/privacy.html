Privacy Architecture & Security Guarantee

Ghostline is built from the ground up on a local-first, zero-telemetry philosophy. Your screen pixels, voice audio, and API keys remain strictly under your control.

100% Offline by Default

When running Ollama + Whisper, screen capture, OCR, and reasoning execute entirely on your CPU/GPU with zero outgoing network packets.

Hardware DPAPI Encryption

Cloud API keys are encrypted at rest using Windows Data Protection API (DPAPI). Keys cannot be read by other Windows user profiles or exported.

Zero Telemetry & Tracking

No analytics, no ping-backs, no user tracking, and no crash reports sent to third-party endpoints. You can audit every line in our open GitHub repository.

Screen-Share Stealth: How Windows Cloaking Works

A common concern during live video calls (Zoom, Microsoft Teams, Google Meet, Webex) is whether assistive overlays might accidentally appear on screen shares:

Native Win32 Exclusion

Ghostline configures its top-level HUD window with the native Windows DWM API attribute: 

SetWindowDisplayAffinity(
    hwnd, 
    WDA_EXCLUDEFROMCAPTURE
);

This instructs the Windows Desktop Window Manager to completely omit the window from screen capture APIs, including Desktop Duplication, GDI capture, and Windows.Graphics.Capture.

What Meeting Viewers See

  • Meeting participants see only the application window or desktop behind Ghostline.
  • Recorded meeting videos will never show the floating answer or hotkey indicators.
  • You retain full visibility on your physical monitor without awkward secondary screens.

How to Independently Verify Our Guarantee

Don't just take our word for it. You can inspect Ghostline with standard Windows networking and packet analysis tools:

  1. Windows Resource Monitor: Press Win + R, type resmon.exe, and check the Network tab. Filter by Ghostline.exe. Notice that 0 outbound connections are made when operating with Ollama.
  2. Wireshark / Fiddler: Run a full packet capture. Filter by DNS or IP packets from the Ghostline process. You will observe complete silence except for local loopback 127.0.0.1:11434.
  3. Source Code Audit: Ghostline is open source. You can audit our HTTP clients in ghostline/core/http_client.py and provider implementations.
