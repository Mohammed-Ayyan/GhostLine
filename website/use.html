Global Hotkey Cheat Sheet

All hotkeys work system-wide regardless of which application is focused, without stealing focus or interrupting your work.

Alt + /

Scan & Solve Screen Question

Hover your cursor over any question on screen and press to trigger silent OCR extraction and reasoning.

Alt + Q

Live Audio Copilot

Opens the floating live transcript panel with dual microphone + video-call loopback transcription.

Alt + T

Toggle Floating HUD

Instantly shows or hides the translucent floating answer overlay.

Alt + Shift + C

Copy Last Answer

Directly copies the latest generated solution or code block to the Windows clipboard.

Alt + 1 / 2 / 3 / 4

Choose Option A / B / C / D

Highlights or selects options in interactive multiple-choice question sessions.

Ctrl + Alt + Q

Emergency Kill Switch

Instantly and cleanly terminates all Ghostline processes, workers, and background threads.

Mode 1: Screen Question Solving

How It Works

  1. Cursor Hover: Place your cursor anywhere inside a question paragraph, quiz prompt, or diagram.
  2. Silent Native OCR: Ghostline captures a high-resolution sub-rectangle around the cursor and runs Windows Runtime OCR (`Windows.Media.Ocr`).
  3. Classification: The prompt engine detects whether the question is Multiple Choice (MCQ), Code Analysis, or Short-Answer Theory.
  4. Fast Reasoning: Your local Ollama model (e.g. `phi3:mini`) computes the answer, confidence level, and step-by-step reasoning.
  5. HUD Display: Results appear in the floating HUD. By default, the HUD does not steal focus, leaving your typing active.

Pro Tips for Screen Solving

  • Dark Mode & Multi-Monitor: Ghostline is fully Per-Monitor V2 DPI aware. Hovering on any monitor automatically detects the correct coordinates and scaling.
  • Auto-Show Toggle: If you prefer the HUD not to appear automatically on scan, disable "Show HUD automatically after a scan" in Settings. You can press Alt + T to view the answer when ready.
  • Caps Lock Pulse: You can enable Caps Lock pulsing in Settings to signal the correct multiple-choice letter silently via hardware keyboard LED.

Mode 2: Live Audio & Video-Call Assistant

Dual-Stream Transcription

Ghostline captures two independent audio channels simultaneously using native Windows WASAPI:

  • Microphone Stream: Captures your voice labeled as [You].
  • Loopback Stream: Captures audio from Zoom, Microsoft Teams, Google Meet, or Discord labeled as [Call].
  • Offline Whisper: Both streams are transcribed locally via faster-whisper and Silero Voice Activity Detection (VAD).

Candidate Profile Grounding

When an interviewer asks a question like "Tell me about a challenging distributed system you designed," Ghostline recognizes the interview context:

  • Answers are generated in authentic first-person candidate voice (e.g., "In my previous role at...").
  • Never introduces itself as an AI or mentions Ghostline.
  • Draws directly from your saved resume facts, education, and technical achievements.

Screen-Share Protection & Stealth Cloaking

Ghostline's HUD overlay window is protected by the Windows API flag WDA_EXCLUDEFROMCAPTURE:

Invisible on Screen Shares: When sharing your screen in Zoom, Microsoft Teams, Slack, or Google Meet, Windows automatically filters out the Ghostline HUD overlay from the captured video feed. You can see the answer clearly on your display, while meeting participants see only your underlying desktop!
