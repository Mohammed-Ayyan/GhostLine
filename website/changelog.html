Release Notes & Changelog

Track updates, feature additions, security enhancements, and bug fixes across all Ghostline versions.

Version 1.0.7

Latest Release
Released on November 8, 2026
GitHub Release

Added

  • HUD Text Entry Focus Controller: Dynamically strips WS_EX_NOACTIVATE when clicking the "Ask your own query" input field in both the MCQ HUD and Live Audio HUD, transfers keyboard focus, and cleanly restores passive stealth and the previous active application on Enter or Escape.
  • Global Shortcuts for Option Selection & Answer Copying: Registered Alt + Shift + C to copy the latest answer to the clipboard and Alt + 1 / 2 / 3 / 4 to choose MCQ options A–D directly from the keyboard.
  • In-Place Streaming Updates: Solving questions with the HUD open now streams tokens and updates answers in-place with zero window flicker or focus-stealing.
  • Adaptive Utterance Endpointing & Faster Answers Mode: Interrogative speech finalizes within 0.45s (0.35s in Early Start mode); added an optional "Faster answers (early start)" toggle in Settings > Audio.
  • Ollama Memory Pinning: Added keep_alive: "5m" and deterministic prompt caching to prevent cold model reloads, reducing voice assistant answer latency to under 1 second.

Fixed

  • HUD Ask Field Keystrokes: Fixed bug where typing in the "Ask" input was ignored by Windows due to extended window styles.
  • Audio Debounce Bottleneck: Reduced speech debounce wait time from 2.0s down to 150 ms (50 ms in early start mode).

Version 1.0.3

Released on November 8, 2026
GitHub Release

Added

  • Rebuilt Master Video Suite: 1080p Launch Film (92s), Setup Tutorial (140s), Usage Walkthrough (180s), and 5 Vertical Shorts (35s) with synthesized electronic soundtrack (-14.1 LUFS), WebVTT subtitles, and text transcripts.
  • Multi-Key Hardware Signalling: Restored physical keyboard LED blinking across Caps Lock, Num Lock, and Scroll Lock (1 pulse for A/True, 2 for B/False, 3 for C, 4 for D).
  • Fluent 2 Dark Website Redesign: Interactive 3D hero app preview, interactive bento grid, accessible modal video player with focus trap, and hardware model advisor.

Fixed

  • Silent Output Mode: Completely eliminated intrusive desktop tray balloon notifications on answer generation.
  • Web Video Faststart: Re-encoded all media assets with +faststart (moov atom at beginning of file) and verified zero static freezes > 1.2s.

Version 1.0.2

Released on November 8, 2026
GitHub Release

Added

  • Native Inno Setup Installer & Portable Distribution: Self-contained zero-dependency installer (Ghostline-Setup.exe) and standalone portable package (Ghostline-Portable.zip) with SHA-256 integrity verification.
  • Candidate Profile Grounding for Interviews: Questions like "Tell me about yourself" are answered directly in authentic first-person candidate voice using the user's saved resume and experience without assistant meta-descriptions.
  • System Tray & Window Lifecycle Controls: Added "Minimize to tray on close" and "Hide window from taskbar" options with immediate Win32 runtime effect (WS_EX_TOOLWINDOW).
  • Cloud Provider Error Mapping & xAI Grok Support: Custom User-Agent headers prevent Cloudflare edge blocking (HTTP 403 / error 1010); friendly error messages replace raw JSON/HTTP error bodies.
  • Self-Contained Diagnostics & Update Checker: Added one-click "Check for Updates" and "Export Diagnostics Bundle" in the Help center with automatic token redaction.

Fixed

  • Input Field Visibility & Contrast: Redesigned all input fields across settings, profile, and provider configurations with distinct surface fills, crisp borders, focused glow states, and readable typography.
  • Label Canvas Background Artifacts: Eliminated dark canvas rectangles ("strips") behind card labels, ensuring clean rendering inside lighter card containers.
  • HUD Non-Stealing Focus & Auto-Show Honoring: Scans via Alt + / strictly respect the "Show HUD automatically after a scan" toggle, never raising or stealing focus when disabled.
  • Live Audio & WASAPI Pipeline Stability: Restored dual-stream microphone and loopback audio capture, Silero VAD segmentation, and Whisper int8 model loading.

Version 1.0.1

Released on October 28, 2026

Added

  • Dual-Stream Audio Pipeline: Simultaneous microphone and system loopback audio capture via Windows WASAPI.
  • Local Speech Transcription: Offline int8 CPU transcription powered by faster-whisper and Silero VAD segmentation.
  • Per-Monitor V2 DPI Awareness: Dynamic coordinate transformation across multi-monitor setups with disparate scaling factors.

Fixed

  • Multi-Line Question OCR Grouping: Fixed truncation issues by grouping adjacent OCR lines into cohesive question blocks.
  • Qt Cross-Thread Signals: Eliminated thread safety race conditions in background audio callbacks.

Version 1.0.0

Released on October 24, 2026

Initial Release

  • Native Windows OCR Engine: High-speed C# Windows Runtime bridge (Windows.Media.Ocr.OcrEngine).

  • Floating HUD Window: Translucent, non-focus-stealing floating window with draggable positioning.
  • Dynamic Tray Indicator: System tray icon displaying status and multiple-choice answer glyphs.
  • Caps Lock Pulse Signaling: Win32 pulsed keyboard LED indicator for discrete signaling.
